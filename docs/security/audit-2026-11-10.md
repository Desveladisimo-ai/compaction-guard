# Independent review, 2026-11-10 (version 0.1.4)

Requested after a user saw the handoff picked up by the wrong session. An independent AI-agent reviewer, given the scenarios and not the maintainer's conclusions, read the code and ran the scripts in a scratch environment (no real state touched). This is not a human third-party audit.

| # | Severity | Finding | Evidence | Disposition |
|---|---|---|---|---|
| 1 | Medium | The announce marker is per project, not per session: the monitor of an older session and the new session's race for it; with both polling together both fired (6 of 6 trials), otherwise the older session won 6 of 8 | ran | Fixed in 0.1.5 as far as the host allows: atomic claim, wording that is harmless without the handoff text. Not fixed: binding to one session (no documented session id for monitors) |
| 2 | Medium | A stale marker never expires and wakes an unrelated later session | ran | Fixed in 0.1.5: markers older than a minute are removed silently |
| 3 | Medium | Autonomous continuation is limited only by the assistant's own rules and the user's permission mode | reasoning | Decided by the maintainer: no freshness window and no opt-in; the user owns the security of their account. The trust boundary is stated in SECURITY.md and the README |
| 4 | Not a vulnerability | Shared computer, same OS account: the plugin adds no access the person did not already have (files, Claude login, permissions); modes 700 and 600 protect against other accounts only | reasoning | Documented |
| 5 | Low | The closing delimiter of an injected note can be imitated by the note | ran | Fixed in 0.1.5: random per-run token |
| 6 | Low | A link planted at the marker path is written through (same account only) | ran | Fixed in 0.1.5: new file plus move. Check-then-use gaps on `pending.md` and `nothing.md` are the same-account kind and are left as they are |
| 7 | Low | The wrap-up derives the project key from `CLAUDE_PROJECT_DIR` or `$PWD`, the session start from the hook's `cwd`; if they differ the handoff is silently not found; keys also differ by path spelling | ran (key difference) | Open, not fixed: whether `CLAUDE_PROJECT_DIR` is set where the skill runs is not yet checked in a real session |

Not covered: real interactive Claude Code sessions (hook and monitor start order, session identifiers).
